# Git Commands

Git - versiyalarni boshqarish tizimi.

- git init - yangi repository yaratish
- git status - holatni tekshirish
- git add . - fayllarni qo‘shish
- git commit -m "message" - saqlash
- git log - tarixni ko‘rish
- git branch - branchlarni ko‘rish
- git checkout - branchga o'tish
- git push - GitHubga yuborish
- git pull - yangilanishlarni olish

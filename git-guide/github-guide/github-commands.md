# GitHub Guide

GitHub - kodlarni internetda saqlash va boshqalar bilan ishlash platformasi.

- Repository - loyiha ombori
- Branch - alohida ish yo‘nalishi
- Commit - o‘zgarishlarni saqlash
- Push - kodni GitHubga yuborish
- Pull - o‘zgarishlarni olish
- Pull Request - o‘zgarishlarni birlashtirish so‘rovi
- Fork - repository nusxasini olish
